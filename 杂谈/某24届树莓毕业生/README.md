# 一些杂录和回忆

初稿起始于2026年7月24日。

零零散散花了很多时间做各种各样的事情，突然想起来自己已经毕业两年了。部门里来了新员工，一个刚毕业的年轻人，然后我才突然意识到自己早就不是刚毕业的大学生了。

人总是失去了才意识到，青春不过四场盛夏，我想，大学毕业的时候，不论是否准备好，青春都会离你而去。

## 大学的句号

2024是我毕业的年份，因为做了毕设替代，所以大学的最后半年我几乎没有出现在学校。在同学和毕设做斗争的时候，我在家里躺平和慢慢地找工作。

我对那段时光的记忆并不深刻，我只记得没有什么事情做，每天想什么时候起床就什么时候起床，想做什么就做什么，然后就是焦虑的四处寻找工作，投简历。那时候我还打了很多游戏，刷了很多B站。我总认为这半年的美好时光是对我大学时光的奖励，虽然，我现在意识到我也没抓住那段时光。

## 大学（？）

我对大学的很多事情都已经记不清了，毕竟20年竟然已经是6年前的事情，我从未感觉时间过的这么快。大学里匆匆茫茫，做过各种各样的事情，做过各种各样的项目。做过新苗大创挑战杯互联网+、在学生会干了两年、自己创建了一个社团又干了一年。从软件干到新媒体干到设计，大学的我给我留下的印象就是活力十足，想做什么就能做什么，想要什么就能去学什么。

我的大学几乎和疫情绑在一起，睁眼闭眼就是核酸健康码，有时候突然有种割裂感，也有点好奇，一个没有疫情的大学生活是什么样的？我不知道，我想，也永远知道不了。

## 项目

大学的时候我踌躇满志，我觉得我必须要做点东西出来，倒不是对自己负责，单纯是想给爸妈证明俺不是孬种。所以去学生会，后面还和室友一起做项目。其实大学生的项目啥也没有，很多东西说白了就是一个概念，一个想法，甚至是导师的一个想法，然后包装成学生项目，用来打比赛。所谓互联网+、大创，其实就是比谁更会包装，谁的项目包装的更完美，有更多专利软著大牛背书，谁就更好。

至于本科生自己做一个项目吗？除非你自己拼实力大一发一篇nature，不然我看还是难上难，没有导师背书寸步难行，学院选拔都不一定能过。

产学研合作其实是个很好的机会，我们还做过和腾讯的产学研合作项目，我还记得那些个日夜兼程赶项目计划书的日子，虽然最后因为项目太多太忙，我没有实际参与项目落地，最后挂了个名。

做项目很忙，但是得奖了可以加绩点，我给自己加到过满绩点（5.0/5.0），因为省级奖、国级奖都能加。

## 学生工作

我的学生工作都在做新媒体，最早是摄影，后面也做设计运营。大一大二在院学生会当成员，大三的时候终于不想干了。其实是因为不喜欢新来的指导老师，不喜欢他说话做事的风格。

原本的指导老师去校党委了，于是原本的指导老师拉着我们这些老同志创立了一个社团，作为校党委的宣传口，我就成了社团的创始人之一、首任社长。

其实大学的学生工作没有网上渲染的那么，官僚主义。至少杭电没有。杭电的学生工作更像是给老师打工，给学院打工，给学校打工。也可能新媒体类的岗位就是这样吧。

能认识很多人，不同专业的，不同性格的。我和很多那时候认识的人现在还保持着联系。我挺推荐做点学生工作的，社团也好，学生会也罢；就当结交点新朋友，认识点人，打发打发时间吧。

## 实习/就业

也许是我大学里最后悔的一段故事之一。

大学时间，我几乎没怎么实习，时间都花在做项目、做学生工作、上学、上课。然后等到要找工作了：什么叫“应届生要求1年工作经验？”。

有点讽刺，但是牢中疯魔的就业市场并不看你做了多少“玩具项目”，绩点刷了多高，拿过多少奖学金多少个人表彰。经济下行期的就业市场只要有用的人，不看这些了。

大学的时候还是太实诚，没有想过把简历包装一下，伪造一点实习。也没想过线上面试的时候搞个AI辅助一下，现在想来就这点小事有什么好实诚的，有工作才是真，该包装就包装。

现在发现大学的时候做的很多事都是浮云，反而有些自己都没在意的事情改变了自己。

就业部分，我决定写其他文档里。毕业两年做了两份工作，每份近乎一年，在我认识的同龄人里竟然还算做的持久的。
